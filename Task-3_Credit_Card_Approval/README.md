# Task 3 – Credit Card Approval Prediction

This project is part of my internship at **Rhombix Technologies**.

## Objective
Build an automatic credit card approval system using Machine Learning.

## Dataset
- application_record.csv
- credit_record.csv

## Techniques Used
- Handling missing values
- Categorical feature encoding
- Feature scaling
- Handling imbalanced data
- Logistic Regression
- Hyperparameter Optimization using GridSearchCV

## Model
- Logistic Regression

## Outcome
An optimized Logistic Regression model was trained to predict credit card approvals effectively.
